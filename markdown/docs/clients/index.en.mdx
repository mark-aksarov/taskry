# Clients

A client is an entity that contains information about a client:

- Full Name — <span className="font-normal">the client's display name.</span>
- About Me — <span className="font-normal">short information about the client shown on the profile page.</span>
- Email — <span className="font-normal">email address used to contact the client.</span>
- Phone Number — <span className="font-normal">the client's phone number.</span>
- Public Link — <span className="font-normal">a link to the client's profile.</span>
- Company — <span className="font-normal">the company associated with the client.</span>

---

## Overview

This section explains how to work with clients and the main features available to users in the system.

### Viewing clients

This section describes how clients are displayed in the system interface. It covers two view modes—list and cards—and the summary information available for each client.

### Client actions

This section covers the main client actions: creating, editing, and deleting clients.

### Search and filtering

This section explains how users can find clients, as well as filtering and sorting options that help narrow the results.

### Companies

This section describes companies and the actions available to users, including viewing the company list, creating companies, editing companies, and deleting companies. A company represents an organization associated with a client and is used to group clients.
