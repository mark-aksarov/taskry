# Import and export

This section describes importing and exporting clients and companies using CSV files. This is useful for bulk record creation, backup, and later recovery of information.

You can prepare a CSV file yourself or download the <Link className="inline text-base" variant="primary" href="/csv-examples.zip" download>CSV examples archive</Link> for import.

---

## Import clients

To import clients into CSV, the following columns must be specified:

- fullName — <span className="font-normal">client full name</span>
- email — <span className="font-normal">client email address</span>
- bio — <span className="font-normal">client bio, optional</span>
- phoneNumber — <span className="font-normal">client phone number, optional</span>
- publicLink — <span className="font-normal">client public profile link, optional</span>
- companyName — <span className="font-normal">client company name, optional</span>

If the file contains a company that does not exist in the system, the import will fail. For a successful import, all related entities must exist beforehand.

To import clients, open the <b>Clients</b> page, click the <b>Manage</b> button, and select <b>Import clients (CSV)</b>.

## Import companies

To import companies, use a CSV with one required column:

- name — <span className="font-normal">company name</span>

Importing companies creates new companies in the current organization and does not modify existing records.

To import companies, open the <b>Companies</b> page, click the <b>Manage</b> button, and select <b>Import companies (CSV)</b>.

## Limitations

The following limitations apply to import and export:

- <span className="font-normal">Only CSV format is supported</span>
- <span className="font-normal">Maximum size of the uploaded file is <b>512 KB</b></span>
- <span className="font-normal">The file must not be empty</span>
- <span className="font-normal">For client import, the required fields are <b>fullName</b> and <b>email</b></span>
- <span className="font-normal">For company import, the required field is <b>name</b></span>
- <span className="font-normal">Import rejects invalid email formats, missing related data, and organization limit overages</span>
- <span className="font-normal">The number of newly created records during import is limited by system limits</span>
- <span className="font-normal">Keep the file in <b>CSV UTF-8</b> format to avoid encoding issues with Cyrillic characters.</span>
- <span className="font-normal">If you use Microsoft Excel, choose <b>CSV UTF-8 (Comma delimited) (*.csv)</b> when saving instead of regular <b>CSV</b>. Regular CSV may use the system encoding, which can cause Cyrillic characters to display incorrectly when importing or opening the file in other applications.</span>
