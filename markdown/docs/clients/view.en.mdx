# Viewing client

Clients are displayed on the <b>Clients</b> page in either a list or card view. On mobile devices, only the card view is available.

A client item in the list or card may include the following data (depending on the view type):

- Full name — <span className="font-normal">the displayed name of the client.</span>
- Avatar — <span className="font-normal">client image.</span>
- Email — <span className="font-normal">email address used to contact the client.</span>
- Phone number — <span className="font-normal">client contact phone number.</span>
- Public link — <span className="font-normal">link to the client profile.</span>
- Company — <span className="font-normal">company associated with the client.</span>

On desktop devices, clicking a client’s <b>name</b> opens a side panel with detailed client information.

On mobile devices, behavior is simplified: tapping a card immediately navigates to the client profile page.

A dedicated <b>actions menu</b> button provides access to additional operations.
