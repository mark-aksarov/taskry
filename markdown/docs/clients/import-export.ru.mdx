# Импорт и экспорт

В этом разделе описывается импорт и экспорт клиентов и компаний с помощью CSV-файлов. Это удобно для массового создания записей, резервного копирования и последующего восстановления информации.

Подготовить CSV-файл можно самостоятельно или скачать <Link className="inline text-base" variant="primary" href="/csv-examples.zip" download>архив с примерами CSV-файлов</Link> для импорта.

---

## Импорт клиентов

Для импорта клиентов в CSV должны быть указаны следующие столбцы:

- fullName — <span className="font-normal">полное имя клиента</span>
- email — <span className="font-normal">электронная почта клиента</span>
- bio — <span className="font-normal">биография клиента, необязательно</span>
- phoneNumber — <span className="font-normal">номер телефона клиента, необязательно</span>
- publicLink — <span className="font-normal">ссылка на публичный профиль клиента, необязательно</span>
- companyName — <span className="font-normal">название компании клиента, необязательно</span>

Если в файле указана компания, которой нет в системе, импорт завершится ошибкой. Для успешного импорта нужно, чтобы все связанные сущности существовали заранее.

Для импорта клиентов на странице <b>Клиенты</b> нужно нажать кнопку <b>Управление</b>, выбрать пункт <b>Импорт клиентов (CSV)</b>.

## Импорт компаний

Для импорта компаний используется CSV с одним обязательным столбцом:

- name — <span className="font-normal">название компании</span>

Импорт компаний создает новые компании в текущей организации и не изменяет уже существующие записи.

Для импорта компаний на странице <b>Компании</b> нужно нажать кнопку <b>Управление</b>, выбрать пункт <b>Импорт компаний (CSV)</b>.

## Ограничения

При импорте и экспорте действуют следующие ограничения:

- <span className="font-normal">Поддерживается только формат CSV</span>
- <span className="font-normal">Максимальный размер загружаемого файла — <b>512 KB</b></span>
- <span className="font-normal">Файл не должен быть пустым</span>
- <span className="font-normal">Для импорта клиентов обязательные поля <b>fullName</b> и <b>email</b></span>
- <span className="font-normal">Для импорта компаний обязательное поле <b>name</b></span>
- <span className="font-normal">Импорт не допускает некорректный формат электронной почты, несуществующие связанные данные и превышение лимитов организации</span>
- <span className="font-normal">Количество новых записей при импорте ограничено системными лимитами</span>
- <span className="font-normal">Сохраняйте файл в формате <b>CSV UTF-8</b>, чтобы избежать проблем с отображением кириллицы.</span>
- <span className="font-normal">Если вы используете Microsoft Excel, при сохранении выберите <b>CSV UTF-8 (разделители-запятые) (*.csv)</b>, а не обычный <b>CSV</b>. Обычный CSV может использовать системную кодировку, из-за чего русские символы могут отображаться некорректно при импорте или открытии файла в других приложениях.</span>
