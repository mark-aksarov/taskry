## Client filtering

To filter clients, go to the <b>Clients</b> page and click the <b>Filters</b> button at the top of the page. A filtering modal will open with the following options:

- No active projects — <span className="font-normal">shows only clients without active projects.</span>
- Has active projects — <span className="font-normal">shows only clients with active projects.</span>
- Has overdue projects — <span className="font-normal">shows only clients with overdue projects.</span>
- Company — <span className="font-normal">filters clients by company.</span>

## Client sorting

To sort clients, go to the <b>Clients</b> page and click the <b>Sort</b> button at the top of the page. The following sorting options are available:

- By full name — <span className="font-normal">sorts clients by full name.</span>
- By company — <span className="font-normal">sorts clients by company.</span>
