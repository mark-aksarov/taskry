# Client actions

This section describes the main client operations: creation, editing, and deletion.

---

## Create client

To create a client on the <b>Clients</b> page, click the <b>Create New</b> button, select <b>Client</b>, fill in the required fields in the form, and confirm creation.

Client creation includes filling in the following data:

- Full name — <span className="font-normal">the displayed name of the client.</span>
- About — <span className="font-normal">a short description shown in the client profile.</span>
- Email — <span className="font-normal">email address used to contact the client.</span>
- Phone number — <span className="font-normal">client contact phone number.</span>
- Public link — <span className="font-normal">link to the client profile.</span>
- Address — <span className="font-normal">client location or address.</span>
- Company — <span className="font-normal">company associated with the client.</span>

After saving, the client will appear in the list if it matches the current sorting, filters, and search conditions.

## Delete client

The system supports two types of deletion: <b>single</b> and <b>bulk</b>. On mobile devices, only <b>single</b> deletion is available. Both options permanently remove a client from the system.

Deleting a client is irreversible, so make sure the client is no longer needed and all important data is preserved before proceeding.

### Single deletion

To delete a client on the <b>Clients</b> page, click the <b>Actions menu</b> (three dots icon) in the client card or list item and select <b>Delete</b>.
