# Краткое руководство

<b>Taskry</b> — это система управления задачами, которая помогает организовать работу команды, контролировать выполнение задач и хранить все важные данные в одном месте.

Основные функции приложения:

- <span className="font-normal">Управление проектами и задачами.</span>
- <span className="font-normal">Поиск и фильтрация проектов и задач.</span>
- <span className="font-normal">Импорт и экспорт данных в формате CSV.</span>
- <span className="font-normal">Приглашение пользователей в рабочее пространство для совместной работы.</span>
- <span className="font-normal">Управление пользователями, клиентами, компаниями, категориями и должностями.</span>

## Приглашение пользователей

Чтобы пригласить коллегу или партнёра в рабочее пространство:

1. <span className="font-normal">Откройте страницу <b>Команда</b>.</span>
2. <span className="font-normal">Нажмите кнопку <b>Пригласить пользователя</b>.</span>
3. <span className="font-normal">Укажите адрес электронной почты.</span>
4. <span className="font-normal">Отправьте приглашение.</span>

Получатель приглашения должен принять его из письма, после чего пройти регистрацию или войти в существующий аккаунт. После подтверждения доступа пользователь автоматически становится участником рабочего пространства.

Важно: пользователей нельзя импортировать как обычные данные. Их нужно приглашать через email.

## Работа с данными

Система поддерживает импорт и экспорт данных. Вы можете переносить и хранить:

- <span className="font-normal">задачи и категории задач.</span>
- <span className="font-normal">проекты и категории проектов.</span>
- <span className="font-normal">клиентов и компании.</span>
- <span className="font-normal">должности.</span>

Импорт пользователей не предусмотрен — для них используется механизм приглашений по email.

Помимо импорта и экспорта, данные можно редактировать напрямую через формы интерфейса:

- <span className="font-normal">создавать, изменять и удалять задачи.</span>
- <span className="font-normal">создавать, изменять и удалять проекты.</span>
- <span className="font-normal">добавлять комментарии.</span>
