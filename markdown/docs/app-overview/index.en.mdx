# Application overview

<b>Taskry</b> is a task management system that helps organize team workflows, track task progress, and store all important information in one place.

Main application features:

- <span className="font-normal">Manage projects and tasks.</span>
- <span className="font-normal">Search and filter projects and tasks.</span>
- <span className="font-normal">Import and export data in CSV format.</span>
- <span className="font-normal">Invite users to the workspace for collaboration.</span>
- <span className="font-normal">Manage users, customers, companies, categories, and positions.</span>

---

## Quick start

To start working with the application, follow a few simple steps:

1. <span className="font-normal">Register in the system.</span>
2. <span className="font-normal">Confirm your email address.</span>
3. <span className="font-normal">Create a workspace.</span>
4. <span className="font-normal">Fill it with demo data.</span>
5. <span className="font-normal">Use the main application features.</span>

## Inviting users

To invite a colleague or partner to your workspace:

1. <span className="font-normal">Open the <b>Team</b> page.</span>
2. <span className="font-normal">Click the <b>Invite user</b> button.</span>
3. <span className="font-normal">Enter the email address.</span>
4. <span className="font-normal">Send the invitation.</span>

The recipient must accept the invitation from the email, then complete registration or sign in with an existing account. After confirming access, the user automatically becomes a member of the workspace.

Important: users cannot be imported as regular data. They must be invited via email.

## Working with data

The system supports data import and export. You can transfer and manage:

- <span className="font-normal">Tasks and task categories.</span>
- <span className="font-normal">Projects and project categories.</span>
- <span className="font-normal">Customers and companies.</span>
- <span className="font-normal">Positions.</span>

User import is not supported — users are added through the email invitation mechanism.

In addition to import and export, data can be edited directly through application forms:

- <span className="font-normal">Create, edit, and delete tasks.</span>
- <span className="font-normal">Create, edit, and delete projects.</span>
- <span className="font-normal">Add comments.</span>
