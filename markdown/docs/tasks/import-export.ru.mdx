# Импорт и экспорт

В этом разделе описывается импорт и экспорт задач и категорий задач с помощью CSV-файлов. Это удобно для массового создания записей, резервного копирования и последующего восстановления информации.

Подготовить CSV-файл можно самостоятельно или скачать <Link className="inline text-base" variant="primary" href="/csv-examples.zip" download>архив с примерами CSV-файлов</Link> для импорта.

---

## Импорт задач

Для импорта задач в CSV должны быть указаны следующие столбцы:

- title — <span className="font-normal">название задачи</span>
- description — <span className="font-normal">описание задачи, необязательно</span>
- deadline — <span className="font-normal">срок выполнения в формате <b>yyyy-MM-dd</b></span>
- status — <span className="font-normal">статус задачи</span>
- projectTitle — <span className="font-normal">название проекта, необязательно</span>
- categoryName — <span className="font-normal">название категории задачи, необязательно</span>
- assigneeEmail — <span className="font-normal">электронная почта исполнителя, необязательно</span>

Если в файле указаны проект, категория или исполнитель, которых нет в системе, импорт завершится ошибкой. Для успешного импорта нужно, чтобы все связанные сущности существовали заранее. Дата обязательно должна быть указана в формате <b>yyyy-MM-dd</b>.

Для импорта задач на странице <b>Задачи</b> нужно нажать кнопку <b>Управление</b>, выбрать пункт <b>Импорт задач (CSV)</b>.

## Импорт категорий

Для импорта категорий используется CSV с одним обязательным столбцом:

- name — <span className="font-normal">название категории задачи</span>

Импорт категорий создает новые категории в текущей организации и не изменяет уже существующие записи.

Для импорта категорий задач на странице <b>Категории задач</b> нужно нажать кнопку <b>Управление</b>, выбрать пункт <b>Импорт категорий (CSV)</b>.

## Ограничения

При импорте и экспорте действуют следующие ограничения:

- <span className="font-normal">Поддерживается только формат CSV</span>
- <span className="font-normal">Максимальный размер загружаемого файла — <b>512 KB</b></span>
- <span className="font-normal">Файл не должен быть пустым</span>
- <span className="font-normal">Для импорта задач обязательны поля <b>title</b>, <b>deadline</b> и <b>status</b></span>
- <span className="font-normal">Для импорта категорий обязательное поле <b>name</b></span>
- <span className="font-normal">Импорт не допускает некорректный формат даты, несуществующие связанные данные и превышение лимитов организации</span>
- <span className="font-normal">Количество новых записей при импорте ограничено системными лимитами</span>
- <span className="font-normal">Сохраняйте файл в формате <b>CSV UTF-8</b>, чтобы избежать проблем с отображением кириллицы.</span>
- <span className="font-normal">Если вы используете Microsoft Excel, при сохранении выберите <b>CSV UTF-8 (разделители-запятые) (*.csv)</b>, а не обычный <b>CSV</b>. Обычный CSV может использовать системную кодировку, из-за чего русские символы могут отображаться некорректно при импорте или открытии файла в других приложениях.</span>
