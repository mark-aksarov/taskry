# Import and export

This section describes importing and exporting projects and project categories using CSV files. This is useful for bulk record creation, backup, and later recovery of information.

You can prepare a CSV file yourself or download the <Link className="inline text-base" variant="primary" href="/csv-examples.zip" download>CSV examples archive</Link> for import.

---

## Import projects

To import projects into CSV, the following columns must be specified:

- title — <span className="font-normal">project title</span>
- description — <span className="font-normal">project description, optional</span>
- deadline — <span className="font-normal">due date in <b>yyyy-MM-dd</b> format</span>
- status — <span className="font-normal">project status</span>
- categoryName — <span className="font-normal">category name, optional</span>
- clientEmail — <span className="font-normal">client email address, optional</span>

If the file contains a category or client that does not exist in the system, the import will fail. For a successful import, all related entities must exist beforehand. The date must be provided in <b>yyyy-MM-dd</b> format.

To import projects, open the <b>Projects</b> page, click the <b>Manage</b> button, and select <b>Import projects (CSV)</b>.

## Import categories

To import categories, use a CSV with one required column:

- name — <span className="font-normal">project category name</span>

Importing categories creates new categories in the current organization and does not modify existing records.

To import project categories, open the <b>Project Categories</b> page, click the <b>Manage</b> button, and select <b>Import categories (CSV)</b>.

## Limitations

The following limitations apply to import and export:

- <span className="font-normal">Only CSV format is supported</span>
- <span className="font-normal">Maximum size of the uploaded file is <b>512 KB</b></span>
- <span className="font-normal">The file must not be empty</span>
- <span className="font-normal">For project import, the required fields are <b>title</b>, <b>deadline</b>, and <b>status</b></span>
- <span className="font-normal">For category import, the required field is <b>name</b></span>
- <span className="font-normal">Import rejects invalid date formats, missing related data, and organization limit overages</span>
- <span className="font-normal">The number of newly created records during import is limited by system limits</span>
- <span className="font-normal">Keep the file in <b>CSV UTF-8</b> format to avoid encoding issues with Cyrillic characters.</span>
- <span className="font-normal">If you use Microsoft Excel, choose <b>CSV UTF-8 (Comma delimited) (*.csv)</b> when saving instead of regular <b>CSV</b>. Regular CSV may use the system encoding, which can cause Cyrillic characters to display incorrectly when importing or opening the file in other applications.</span>
