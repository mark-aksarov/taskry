# Импорт и экспорт

В этом разделе описывается импорт и экспорт пользователей и должностей с помощью CSV-файлов. Это удобно для массового создания записей, резервного копирования и последующего восстановления информации.

Подготовить CSV-файл можно самостоятельно или скачать <Link className="inline text-base" variant="primary" href="/csv-examples.zip" download>архив с примерами CSV-файлов</Link> для импорта.

Пользователей нельзя импортировать напрямую через CSV, потому что их учетные записи создаются и управляются через приглашения.

---

## Импорт должностей

Для импорта должностей используется CSV с одним обязательным столбцом:

- name — <span className="font-normal">название должности</span>

Импорт должностей создает новые должности в текущей организации и не изменяет уже существующие записи.

Для импорта должностей на странице <b>Должности</b> нужно нажать кнопку <b>Управление</b>, выбрать пункт <b>Импорт должностей (CSV)</b>.

## Ограничения

При импорте и экспорте действуют следующие ограничения:

- <span className="font-normal">Поддерживается только формат CSV</span>
- <span className="font-normal">Максимальный размер загружаемого файла — <b>512 KB</b></span>
- <span className="font-normal">Файл не должен быть пустым</span>
- <span className="font-normal">Для импорта должностей обязательное поле <b>name</b></span>
- <span className="font-normal">Импорт пользователей через CSV не поддерживается</span>
- <span className="font-normal">Импорт не допускает некорректный формат данных, несуществующие связанные записи и превышение лимитов организации</span>
- <span className="font-normal">Количество новых записей при импорте ограничено системными лимитами</span>
- <span className="font-normal">Сохраняйте файл в формате <b>CSV UTF-8</b>, чтобы избежать проблем с отображением кириллицы.</span>
- <span className="font-normal">Если вы используете Microsoft Excel, при сохранении выберите <b>CSV UTF-8 (разделители-запятые) (*.csv)</b>, а не обычный <b>CSV</b>. Обычный CSV может использовать системную кодировку, из-за чего русские символы могут отображаться некорректно при импорте или открытии файла в других приложениях.</span>
